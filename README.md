Fiber Profile Analysis scripts for the QC and analysis steps of fiber profile data
* computation of diffusion models (DTI, FW-DTI, NODDI)
* QC of atlas registration using a population model of expected deviations from atlas
* flip tensor helper when incorrect orientation is present
* combine fiber profile files (fvp) into a CSV spreadsheet
* impute profiles using a whole brain fiber axis model and INR-imputation
* QC of profiles using a population model of expected deviations from the normative model
* reformat the motion QC from the DWI preprocessing for easy downstream use
